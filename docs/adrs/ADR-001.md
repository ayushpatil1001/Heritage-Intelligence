# ADR-001: Hybrid Search & Strict Citation Grounding for Historical Heritage

## Status
Accepted

## Context
In historical and constitutional archives, particularly concerning national icons like Dr. B. R. Ambedkar, automated conversational AI systems risk generating hallucinations, anachronisms, or misattributed quotations. In institutional and museum contexts, a single fabricated quotation severely undermines institutional credibility.

## Decision
1. We mandate **Hybrid Retrieval** combining dense vector embeddings (cosine similarity) and sparse lexical retrieval (`tsvector` / BM25) fused via Reciprocal Rank Fusion (RRF).
2. We enforce a **Hard Grounding Contract**:
   - The LLM prompt is strictly instructed: *You are an archival assistant answering exclusively from the provided source excerpts. If the excerpts do not contain the answer, explicitly state that no record exists.*
   - All generated statements must map to bracketed citation indices `[S1]`, `[S2]`, which are checked programmatically before outputting.
   - For quote verification, an exact and cosine similarity pipeline compares candidate text against the entire primary corpus. If below similarity threshold $\tau = 0.70$, the system classifies it as *Not Found in Primary Corpus* with nearest semantic matches.

## Consequences
- **Positive:** Zero invented facts, transparent provenance, auditability for researchers, 100% citation coverage on evaluated benchmarks.
- **Negative:** Queries outside the indexed corpus will not produce synthetic speculative answers. This is an intentional design trade-off prioritizing historical veracity over conversational verbosity.
